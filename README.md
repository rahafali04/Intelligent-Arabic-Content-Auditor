# 🔍 Intelligent Arabic Content Auditor & News Classifier

An end-to-end Arabic NLP and Machine Learning pipeline for text cleaning, feature extraction, and automated news classification using Support Vector Machines (SVM).

## 🚀 Key Features
- **Preprocessing Pipeline:** Custom Arabic normalization, Stop-words removal, and ISRI Stemming.
- **Linguistic Analysis:** POS Tagging and Named Entity Recognition (NER) using `Stanza`.
- **Feature Extraction:** TF-IDF Vectorization and Word2Vec Document Embeddings.
- **Classification:** Linear SVM model achieving **90.91% Accuracy**.

## 📊 Performance & Results
- **Accuracy:** 90.91%
- **Models Evaluated:** Support Vector Classifier (SVC) with TF-IDF features.

## 🛠️ Tech Stack
- Python, Pandas, NumPy
- NLTK, Stanza, Gensim (Word2Vec)
- Scikit-learn, Matplotlib, Seaborn
